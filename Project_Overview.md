# Project Overview

## Project Title

AdventureWorks Sales Analytics Dashboard | Microsoft Power BI

---

## Objective

The objective of this project is to analyze AdventureWorks sales data and build an interactive business intelligence dashboard that helps stakeholders monitor sales performance, profitability, customer behavior, product performance, and return trends.

---

## Dataset

AdventureWorks Sales Dataset

The dataset includes information about:

- Sales Transactions
- Products
- Customers
- Territories
- Product Categories
- Product Subcategories
- Calendar
- Returns

---

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Microsoft Excel

---

## Dashboard Pages

- Executive Dashboard
- Map Dashboard
- Product Details
- Customer Details

- Q&A
- Decomposition Tree
- Key Influencers

## Key Performance Indicators (KPIs)

- Total Revenue

- Total Customers

- Quantity Returned

## Skills Demonstrated

## Outcome

The dashboard provides meaningful business insights that help analyze sales performance, customer trends, product performance, and regional sales, enabling data-driven decision-making.
